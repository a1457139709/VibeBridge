# VibeBridge：多项目 Agent 工作台

VibeBridge 是面向个人日常工作的多项目 Agent CLI 工作台。本词汇表区分工作台的面板与布局、CLI 维护的对话，以及一次实际运行。

## Language

### 工作组织

**工作台（Workbench）**：
用户管理多个项目、在项目之间切换并通过终端面板操作 Agent CLI 的应用。
_Avoid_：IDE、自动任务调度器（由 Agent 自主分派任务）、Agent 协作平台

**项目（Project）**：
工作台中仅关联一个本地目录的工作单元，拥有自己的面板配置与布局。
_Avoid_：仓库（目录不一定是 Git 仓库）、受管会话集合、窗口组

**项目目录（Project Directory）**：
项目在工作台中关联的本地目录，作为之后启动 Agent 运行实例的默认目录；已启动实例的实际工作目录可以与当前项目目录不同。
_Avoid_：独立工作副本、隔离目录、面板专属目录

**删除项目（Delete Project）**：
将项目及其面板配置和布局从工作台移除的用户操作，本地目录、文件及 CLI 历史不属于其删除范围。
_Avoid_：删除项目目录、清空文件、删除 CLI 会话

**Agent 类型（Agent Type）**：
某一种通过 CLI 交互的 Agent 工具，例如 Claude Code、Codex CLI 或 pi；同一类型可以有多个运行实例。
_Avoid_：模型、厂商、会话、桌面应用

**Agent 类型色（Agent Type Color）**：
工作台中与某一种 Agent 类型固定关联、用于辨认该类型的色系；同类型的图标、面板与导航采用一致的类型色关系。类型色本身不表示是否选中或正在运行。
_Avoid_：通用强调色、项目色、随机面板色、任务状态色

**Agent 设置（Agent Settings）**：
工作台中按 Agent 类型统一管理、供各项目使用的启动设置。
_Avoid_：Agent 实例、会话身份、项目专属 Agent

### 布局与交互

**主窗口（Main Window）**：
工作台的应用窗口，包含项目导航以及当前项目的布局区域。
_Avoid_：Agent 面板、终端会话

**项目导航（Project Navigation）**：
主窗口中列出项目及其 Agent 面板的区域，提供切换项目、定位面板、添加项目和打开设置的入口；可折叠并调整宽度。
_Avoid_：布局区域、文件浏览器、历史会话列表

**布局区域（Layout Area）**：
主窗口中用于平铺当前项目全部常驻面板的区域，不包括项目导航和临时面板托盘。
_Avoid_：整个屏幕、某个终端的历史输出区

**Agent 面板（Agent Panel）**：
项目中可新增、关闭和调整的一个终端交互区域，承载所选 Agent 的运行实例或显示其未运行状态。手动缩至最小时仍以可辨认的会话标题和 Agent 类型标识呈现，保留原面板身份与运行实例。
_Avoid_：独立桌面窗口、固定槽位、会话本身、Agent 类型

**常驻面板（Resident Panel）**：
位于布局区域、参与平铺的 Agent 面板；只来自项目创建，或由用户把面板拖入布局区域。重开应用时随恢复布局重新呈现。
_Avoid_：主面板、长期角色、固定槽位

**临时面板（Ephemeral Panel）**：
位于临时面板托盘、不占布局空间的 Agent 面板；工作区中新增的 Agent 面板一律先成为临时面板。用户可随时把它拖入布局区域成为常驻面板，或把常驻面板移入托盘，重开应用时不恢复。面板是常驻还是临时只看它当前在哪里，与它由派发还是手动产生无关。
_Avoid_：次要面板、派发面板、浮动窗口

**临时面板托盘（Ephemeral Panel Tray）**：
布局区域下方列出当前项目临时面板及其处理状态的窄条；从这里打开的临时面板以临时放大呈现。
_Avoid_：向上展开的输出条、状态汇总、任务栏

**项目汇总（Project Summary）**：
工作区中按处理状态（就绪、等待输入、本轮结束、异常）统计当前项目全部 Agent 面板（常驻与临时）并可从中定位面板的部分；只在工作区可见，离开工作区时状态只看项目导航。
_Avoid_：全局状态栏、跨项目汇总、临时面板托盘

**面板配置（Panel Configuration）**：
工作台为某个面板保留的 Agent 类型选择。
_Avoid_：会话上下文、会话恢复标识、进程快照

**布局配置（Layout Configuration）**：
一个项目的面板集合、排列关系和相对大小所构成的空间安排。
_Avoid_：CLI 会话历史、临时放大状态、任务运行状态

**面板位置关系（Panel Spatial Relationships）**：
Agent 面板之间的左右、上下方位关系，是用户辨认面板所在位置的空间依据。
_Avoid_：固定像素坐标、面板大小不变、面板面积相等

**面板最小尺寸（Minimum Panel Size）**：
手动拖动分隔线缩小面板时，为保留可辨认的会话标题、Agent 类型标识和面板边界而设置的宽高下限；它不限制主窗口缩小。
_Avoid_：主窗口最小尺寸、终端可读性保证、创建或启动门槛

**交换预览（Swap Preview）**：
拖动面板并悬停在另一个常驻面板中部时，对本次交换结果的临时展示；只有在有效目标上松手才提交交换。
_Avoid_：已保存布局、连续交换、运行实例迁移

**落点预览（Drop Preview）**：
拖动面板悬停在某个常驻面板四周或布局区域边缘时，对松手结果的临时展示：被拖面板切开目标面板，或占满布局区域的一整侧；只有在有效落点上松手才提交。
_Avoid_：已保存布局、自动插入位置、交换预览

**项目创建引导（Project Setup）**：
确认新项目目录后，用于选择窗口总数并按 Agent 类型配置初始数量的简单页面。
_Avoid_：布局预览编辑器、逐格分配界面、每次进入项目的确认页、Agent 安装向导、只有单个大终端的初始工作区

**自动排布（Automatic Arrangement）**：
依据当前面板集合及布局规则形成平铺安排的行为；只在项目创建时安排初始常驻面板，工作区中不会自动为新面板找位置。
_Avoid_：固定空槽位、自由重叠浮窗、滚动网格

**临时放大（Temporary Maximize）**：
临时让单个 Agent 面板占据布局区域的查看方式，退出此状态后返回原布局。
_Avoid_：修改保存布局、删除其他面板、结束其他实例

**恢复布局（Restore Layout）**：
依据保存的面板配置和空间安排重新呈现项目工作区的行为。
_Avoid_：恢复 Agent 对话、恢复进程、自动续写任务

### 会话与运行

**会话（Session）**：
由 Agent CLI 维护、具有对话身份与上下文的一次持续对话；同一会话可以经历多次运行实例，同一运行实例也可以因用户在 CLI 中新建或恢复对话而先后承载多个会话。
_Avoid_：面板、进程、终端画面、单轮回复、业务任务

**会话标题（Session Title）**：
Agent CLI 为会话自动生成或由用户在 CLI 中修改的名称；工作台只显示它，不生成也不修改。尚未命名时显示随界面语言切换的工作台占位（English 为 Untitled task，简体中文为“未命名任务”），真实会话标题保持原样。
_Avoid_：任务名称、面板别名、终端标题、Agent 类型名

**历史会话（Historical Session）**：
CLI 已保存、可通过其原生历史功能查找的既有对话。
_Avoid_：工作台维护的历史列表、关闭的面板、终端输出记录

**会话恢复标识（Session Resume Reference）**：
能够精确指向某个既有会话、供对应 CLI 恢复它的标识；可以是会话 ID 或会话文件标识。
_Avoid_：面板编号、项目目录、最近一次会话

**恢复会话（Resume Session）**：
通过 CLI 的恢复能力重新进入既有对话上下文的行为；本项目讨论的手动恢复由用户在原生 CLI 交互中发起。
_Avoid_：恢复布局、新建对话、重放旧终端画面

**运行实例（Agent Run）**：
由工作台在某个面板中启动、持续一段时间的 Agent CLI 运行。用户可在其中通过 CLI 原生操作先后切换到多个会话，面板状态始终反映当前会话；被 CLI 移交给其他进程继续运行的会话（如 CLI 自身的后台会话）不再属于该运行实例。
_Avoid_：Agent 类型、Agent 设置、持久会话身份、面板本身

**运行实例管理（Run Supervision）**：
工作台对每个运行实例从启动、观察其处理状态到结束与收尾的整体看管；它判断一次启动是成功、失败还是未确认，以及一次结束是工作台主动停止的，还是运行实例自行退出的（自行退出可能是 Agent 正常结束，不等于异常或任务失败），而面板、布局与项目的随之调整不属于它。
_Avoid_：会话管理、面板管理、进程守护服务

**状态上报器（Status Reporter）**：
工作台随运行实例一同交给 Agent CLI 加载、借助该 CLI 原生的事件机制把处理事实上报给工作台的部分；它只观察并上报，不替 CLI 做决定、不改变 CLI 的输出或行为，上报失败也不影响用户继续操作终端。每种 Agent 类型各有一个。
_Avoid_：hook、extension、插件、常驻观察进程

**关闭面板（Close Panel）**：
从项目布局中移除某个面板并结束其运行实例的用户操作。
_Avoid_：退出应用、删除 CLI 历史、保留固定空位

**撤回新增面板（Withdraw New Panel）**：
新增面板或项目创建引导中某个面板的 Agent 无法启动时，撤销这次新增、使面板配置与布局回到新增前的行为；恢复布局与编辑项目重启时的启动失败保留面板，未确认的启动也不撤回。
_Avoid_：关闭面板、运行退出后移除面板、自动换用其他 Agent

**终端记录（Terminal Record）**：
终端呈现的输入输出内容，可用于回看操作过程，与 Agent 自身保存的对话上下文不同。
_Avoid_：Agent 记忆、会话恢复标识、任务成功证明

**后台运行（Background Execution）**：
工作台仍在运行时，非当前项目或暂时不可见面板中的运行实例继续执行的状态。
_Avoid_：退出应用后留存的后台服务、自动恢复对话、附属任务

**附属任务（Spawned Task）**：
主 Agent 在一轮处理中发起、不阻塞主 Agent 继续或结束回复的 sub-agent 或后台命令，包括长期运行的后台进程。
_Avoid_：后台运行、派发、独立会话

**退出工作台（Quit Workbench）**：
用户确认后结束整个应用及其管理的运行实例，同时保留项目、面板配置和布局的操作。
_Avoid_：逐个关闭面板、删除 CLI 历史、仅隐藏主窗口

**本轮结束（Turn Ended）**：
Agent 结束一轮处理且该轮发起的附属任务都已结束的状态；主 Agent 已停止回复但仍有附属任务在运行时，该轮尚未结束。其含义不等于用户的完整业务任务已经成功完成。
_Avoid_：任务成功、主 Agent 停止回复、面板关闭、进程退出

### 仓库与派发

**Forge**：
托管仓库及其 issue 与 pull request 的服务，例如 GitHub；工作台通过与具体 Forge 无关的接口使用它，每个 Forge 一个适配器，身份取自该 Forge 的 CLI 当前激活的账号。
_Avoid_：代码托管平台、issue tracker（只管 issue，没有仓库与 pull request）、GitHub 网关、Git 远程、项目目录

**仓库绑定（Repository Binding）**：
用户在项目建好之后，从 Forge 的 CLI 当前账号自己、协作或所在组织的仓库中为项目选定的一个仓库，记为 Forge 与仓库路径；每个项目至多绑定一个，未绑定的项目没有 issue 与 pull request 视图。项目目录的 `origin` 指向的仓库只决定默认选中哪一个，用户保存后才算绑定。
_Avoid_：从项目目录推断的仓库、任意粘贴的仓库地址、项目目录、多仓库项目

**Forge 侧边栏（Forge Sidebar）**：
主窗口右侧显示当前项目所绑定仓库的 issue 与 pull request、并从中派发的区域，标题按所绑定的 Forge 显示；未绑定的项目只显示空状态与绑定入口。开关状态与宽度全应用共用一份，打开时按设置挤压或覆盖布局区域，在设置页时仍然显示。
_Avoid_：Issue 侧边栏（它也显示 pull request）、GitHub 侧边栏（Forge 不止 GitHub）、项目导航、详情

**Pull request**：
仓库中请求把一个分支合入另一个分支的提议，连同它的评审与检查结论；不论绑定的是哪个 Forge，都沿用 GitHub 的这个名字。
_Avoid_：合并请求、merge request、MR

**派发（Dispatch）**：
用户手动把某个 issue 连同自己选定的一段预设指令交给某个 Agent 面板的操作：指令进入面板的输入，按指令约定直接提交或只填入，不顾及面板当时在做什么；每次派发在接手的会话确定后留下一条派发记录。
_Avoid_：自动调度、Agent 自主分派、任务队列、默认派发

**派发记录（Dispatch Record）**：
某次派发留下的事实：哪个 issue、何时、以什么指令交给了哪个会话。它指向会话而非面板，关联只从 issue 指向会话；之后面板关闭、会话切换、issue 关闭或重开应用都不改变它。查看时若某个打开的面板正处在该会话上，可以定位到那个面板，否则只呈现记录本身。
_Avoid_：面板与 issue 的绑定、面板上的 issue 标记、任务队列、issue 完成状态

**工作流（Workflow）**：
用户在 Agent CLI 中依次显式调用的一组 skills 所构成的工作方法，例如 Matt 的流程；它可以是有先后顺序的链条，也可以只有一个入口。工作台不执行、也不编排工作流，只通过派发把其中的一步交给面板。工作台内置若干工作流，用户在设置中逐个开启；开启后其中可派发的步骤才出现在派发菜单中，未开启的工作流不出现。
_Avoid_：skills 流、自动流水线、CI 工作流、任务编排

### 设置与提示

**设置草稿（Settings Draft）**：
设置页某一分类中已修改但尚未保存的值；只有用户手动保存后才写入配置并生效，放弃或不保存即丢弃。
_Avoid_：自动保存、已生效设置、配置文件

**设置冲突（Settings Conflict）**：
设置中各字段各自合法，但字段之间不能同时成立的状态。读入的设置存在冲突时照常生效，工作台启动后以不可关闭的对话框要求前往对应设置修正，修正前不能离开设置；保存时存在冲突则该分类不能保存。目前唯一的设置冲突是快捷键冲突。
_Avoid_：无效配置、配置损坏、非法值、默认快捷键冲突

**快捷键冲突（Shortcut Conflict）**：
两个或多个动作，或某个动作与系统保留操作，使用同一组合键的状态；它是一种设置冲突。冲突期间同一组合键由动作列表中靠前的动作响应。
_Avoid_：无效组合键、已生效的冲突绑定

**临时提示（Transient Notice）**：
对一次操作结果的简短告知，显示一段时间后自动消失，不要求用户做出选择。
_Avoid_：确认对话框、字段高亮、持续状态说明、Agent 任务状态通知
