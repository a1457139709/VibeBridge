## Agent skills

### Coding standards

Before writing, changing, or reviewing code or tests, read `CODING_STANDARDS.md`.

### Prototypes

Prototypes live on `prototype/*` branches. The prototype is the authority on visible UI and interaction. Frontend code may start from its components and styles, wired to the data interfaces the spec defines; record each deviation a real constraint forces (such as paging a long list) in the spec or ticket. Derive backend behavior, state ownership, data models, and lifecycle rules from the spec, issue resolutions, and ADRs.

### Issue tracker

Issues and specs are tracked in GitHub Issues. Before ticket operations, read `docs/agents/issue-tracker.md`.

### Triage labels

The five triage roles use their default label names. Before triage, read `docs/agents/triage-labels.md`.

### Domain docs

Single-context domain docs. Before exploring the codebase, read `docs/agents/domain.md`.
