## 配置约定

用户设置只写入 `settings.json`，SQLite 只保存项目及实际布局。文件缺失使用默认值，损坏或读取失败明确提示并保留原文件。保存完整写入临时文件后替换，应用内串行异步执行；保存失败不更新有效配置。退出应用后再手改配置，下次启动读取；没有文件监听、主题热切换、CLI 主题同步或外部并发编辑合并机制。
