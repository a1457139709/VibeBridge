日期：2026-10-07。规格依据：#24，以及 #22 / #23 的最终决议。产品独立实现，未读取或复用原型代码、结构或后端设计。

## 自动化范围

沿用规格中用户已确认的边界：工作台业务操作入口、创建界面、外部 CLI 边界及最终保存/退出结果。不查询 SQLite 内部字段，不复制布局算法作为测试，不建立截图回归或主题/尺寸矩阵。

已验证：

- 名称为空、目录无效、分配不一致时拒绝创建；未确认和取消均不创建运行。
- 初始 0 / 3、总数修改保留分配、超额禁止创建、取消后保留本次应用内草稿。
- 三种类型按 Codex、Claude Code、pi 分组创建，使用实际项目目录。
- 真实 PTY 中三路独立输入，尺寸变化传到进程；失效运行输入返回错误。
- 共用业务操作限制十个面板；启动失败保留对应类型并报告失败。
- 退出后重开保留面板身份和实际布局，但创建新的运行身份；关闭面板会删除其保存配置。
- 正常退出清理运行及测试中的脱离进程组子进程；取消退出保留原运行。
- 配置损坏明确报告且不被退出保存覆盖。
- 正式 Electron 窗口创建、终端键盘输入、创建页往返、取消与确认退出。
- 打包应用内的产品代码和原生模块可运行同一桌面流程；实际 `.app` 可打开创建页并显示原生退出确认。

终端兼容环境已读取版本：Codex CLI 0.160.1、Claude Code 2.1.288、pi 0.84.4。版本与路径检查不等于完整交互验收。

## 待用户验收

1. 从 Finder 打开 `outputs/VibeBridge.app`，选择一个本地目录，三种 Agent 各分配一个并创建，确认各 CLI 与在本机终端中的启动一致。
2. 分别输入中文、粘贴多行、选择复制、使用控制键；在 CLI 内手动选择或恢复历史会话。检查原生颜色、重绘与当前运行滚动回看。
3. 调整主窗口和分隔线、从面板顶部交换位置；返回创建页再取消，检查终端画面与输入目标。检查三面板上大下二及整体视觉、间距、颜色。
4. 关闭主窗口时先取消，确认运行继续；再确认退出。重开后检查项目、面板和布局保留，CLI 新启动但未自动恢复会话。

跨项目大规模持续输出、异常强杀、短寿命双重 fork 后代、完整故障互清理与全部真实 CLI 体验留给后续完整验收。本票实现基础进程身份跟踪和有界清理，不把一次可控子进程测试标作完整故障保证。
