## 待用户验收

1. `npm run dev` 打开正式应用，在同一项目启动三种 Agent。通过右上角“＋”新增，检查居中纵向弹窗、背景可见、名称与图标、常驻面板按钮和品牌焦点色；同类面板不加编号。
2. 拖动横向与竖向分隔线，再从顶部拖到另一面板的正文区域交换。检查连续平铺、文字选择、顶部按钮独立响应；拖出目标、按 Escape 或切到其他窗口后，反馈应消失。
3. 放大并还原，缩小主窗口到较小尺寸后继续输入。检查原有 CLI 未重启、输入目标与重绘正确，布局区域不滚动、不强制扩窗；开启系统“减弱动态效果”后检查过渡关闭。
4. 调整比例与排列后退出、重开，检查面板对应关系。关闭最后一个面板再重开应仍为空；用空项目入口新增。分别在 CLI 内正常退出与终止运行，确认面板移除；退出应用后重开则保留面板。
