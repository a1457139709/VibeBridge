# 运行实例和终端只相信宿主确认过的事实

运行实例管理、终端宿主和渲染进程的终端之间的事件可能乱序、迟到或丢失。进程的生命周期以终端宿主报告的为准，其他各方只相信它确认过的事实。

- **启动结果分为确认、失败和未确认**：没有收到宿主的回应，不能证明进程没有启动。未确认的启动可能仍在运行，已观察到的运行实例保留，继续接受它之后的事件，不隐式重试。只有失败的启动才确定没有启动。
- **不由工作台停止而结束的运行不是故障**：Agent 正常退出（例如在 CLI 里 `/exit`），既不表示故障，也不表示任务失败。
- **托盘面板留在它启动时的目录里**：项目目录改变时只重启常驻面板。
- **输出从不截断**：流控覆盖从宿主到屏幕的每一跳。
- **会话标题只从终端标题信号里观察**，看不懂的格式保留为未知，不猜测。
