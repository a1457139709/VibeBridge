# 渲染进程立即显示意图，输入只去用户明确指定的地方

渲染进程里，快照、IPC 回应、DOM 事件和动画的到达顺序都不受控制。下面这些决定保证界面及时反映用户的操作，而键盘输入永远不会落到用户没有指定的终端上。

## 快照与乐观显示

- 每个快照到达就绘制，不合并（`Workbench.tsx`）：布局区域比较相邻两次保存的布局，把两个快照合进一次渲染，可能藏住一次回到上上次布局的保存。
- 侧边栏的打开状态和宽度（`sidebar-preferences.ts`、`ForgeSidebar.tsx`）：切换和拖动立即显示并保存，保存失败就回到主进程最近存下的偏好。较新的操作替换待定的操作，快照不会替换待定操作的预览。偏好在送达时观察，与 React 对快照的批处理无关；旧的写入只用于失败恢复，不会成为下一次操作的基础。打开侧边栏时先设好意图，因为这次保存的快照可能已经画出打开的侧边栏。这些 hook 活在主窗口的整个生命周期里。
- 面板拖放（`panel-interactions.ts`）：放下立即显示，不等保存回来；保存的布局等于手势计算时所依据的布局时，手势和显示的布局仍然有效。
- 直接操作（`ForgeDetail.tsx`）没有乐观更新：成功后报告，等主进程推来 Forge 此后的状态再显示。
- 新面板可能比加入它的快照先得到回应（`DispatchMenu.tsx`、`panel-location.ts`）：要定位的面板先记下，等快照里出现再定位；新打开的托盘面板不经校验直接设为视图。
- 侧边栏总是显示当前项目，所以从绑定入口打开它时，那个项目成为当前项目（`Workbench.tsx`）。编辑项目改了目录时，绑定不跟随新目录的 origin（`ProjectManagement.tsx`）。

## 键盘输入与焦点（`panel-location.ts`）

- `selected` 总是常驻面板；`maximized` 是占据布局区域的那一个面板，可以是常驻面板，也可以是打开的托盘面板（它的临时最大化）。接收键盘输入的是 maximized，否则是 selected。
- 为了让工作区可用而显示的后备视图，不是被取消的请求授权的输入目标；等用户明确选择新的目标。
- 面板显示了但还没有输入接收者时，键盘命令不能让输入留在之前的终端上。
- 快照变化可以更新显示的选择，但当某个控件或列表拥有键盘时，只有明确的定位才能拿走焦点。
- `focus()` 同步派发焦点事件；它们是反馈，不是替换引起它们的那个操作的用户命令。
- 定位用的 IPC 不能撤回：迟到的结果可以改变快照，但只有仍然有效的那次操作能安排焦点或报告成功。
- 标题栏和最大化操作在终端已经可见时立即接受输入；只有未挂载或隐藏的目标要等一帧。
- 两个 hook 共享私有的执行状态；工作区被替换时只断开它的 DOM，已接受的操作和项目视图留在根上。
- 对话框要在字段的 effect 运行之前打开：字段只能在打开的对话框里获得焦点（`ProjectManagement.tsx`）。

## 拖放（`panel-drag.ts`、`panel-interactions.ts`、`panel-tray.css`）

- 落点：布局区域的边缘带填满那一侧；另一个常驻面板中间三分之一（宽和高）与它交换；面板其余部分在离指针最近的边上拆分。命中测试用拖动之前的区域，从不用显示中的预览。
- 拖动时冻结的副本只是绘制表面，从不拥有终端、输入或布局。
- 空托盘叠在布局区域底部之上，所以拖动时显示它不会改变面板尺寸；布局的落点（包括边缘带）在它上面。
- `pointerup` 可能在没有最后一次 `pointermove` 的情况下送达。从托盘卡片开始的拖动以卡片上的一次 click 结束，这次 click 落在画布外。
- 活动指针结束或取消之前，忽略重叠的开始；第二个指针不能抢走第一个指针的捕获。
- 每次 DOM 提交（包括标题和运行变化）后更新观察；模块负责观察，调用方只渲染布局并保存有效的提交。

## 尺寸与测量

- 窗口只限制区域怎样绘制，从不改变它们记住的宽度（`region-widths.ts`、`Workbench.tsx`）。导航和侧边栏分享窗口宽度，详情和侧边栏也是；详情可以盖住导航。最后调整的区域保持宽度直到窗口宽度，其他区域画窄些，记住的宽度不变。每条拖动边都留在窗口里。
- 面板标题用实际的 UI 字体测量（`panel-measurement.ts`）；紧凑外框有自己的尺寸，测量它不依赖当前的行或堆叠布局。有界前缀的一半允许两行；即使独立缩短的面板需要单行条，图标和间距仍然可用。隐藏的设置或项目视图没有布局，不是真的很小的面板。普通外框即使从小面板的流里移除，也继续测量。
- 尺寸不足的叶节点在长大期间，反向拖动时不能让出这部分空间；到达正常最小值后恢复普通的双向调整（`panel-resize.ts`）。
- 隐藏的面板保持挂载，终端保留屏幕（`Workspace.tsx`）；紧凑面板只抑制绘制，真实终端保留几何、选择和输入焦点（`agent-panel.css`）。
- 项目摘要的名字加两侧给 ＋ 留的空间，在任一语言下都在接近 `project-summary.css` 里那个宽度时放不下；此时所有名字一起收起，只留图标和计数。

## 浏览器与平台

- 原生 `title` 提示在工作台窗口里不显示，所以应用自己画悬停提示（`HoverHints.tsx`）：元素用 `data-hint` 标记，指针或键盘焦点下最内层的那个胜出。按下会开始点击或拖动，提示让开，直到指针进入另一个元素；提示文本每次渲染都跟随元素，所以位置也跟随。
- 每个 Busy 图标的旋转都锚定在文档时间线的原点上，无论动画何时开始，所有 Busy 图标同相；解除减弱动态效果后重新锚定（`ProcessingStatusIcon.tsx`）。
- 定位动画自己负责两个 100ms 的半程；布局插值会多加一层过渡（`agent-panel.css`）。飞行动画期间，另一个面板可能已经占据了布局区域（`tray-flight.ts`）。
- 虚拟化的行可能在停留的指针或焦点下卸载，此时它们不停留在任何行上（`row-resting.ts`）。
- macOS 上 ⌥+Space 会键入另一个字符：按键判断用 Space 键本身，不看它键入了什么（`DispatchMenu.tsx`）。
- 浏览器在反复按 Escape 后仍可能关闭模态框，所以设置冲突对话框关闭后重新打开（`SettingsConflict.tsx`）。
