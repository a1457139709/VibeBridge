# 每道进程边界检查收到的东西，外来内容不能运行

工作台由渲染进程、主进程、存储 worker、终端宿主和 Agent CLI 组成。数据跨过任何一道边界，都由接收方按共享的 schema 读一遍再用；来自 Forge 或用户环境的内容不能在页面里运行、加载或泄露。

- **接收方检查形状**：每道边界的两边都按同一份定义解析对方的消息，谁也不信任对方。边界只检查形状，值的含义由业务模块判断。主进程只回答本窗口当前显示的页面发来的请求。
- **消息带信封跨进程**：错误和通知以字符串跨过进程边界时带一个显式的信封，不靠匹配翻译后的句子。只有信封里显式嵌套的消息会被格式化，用户名、路径和外部详情逐字节不变。
- **存储按声明读取**：存储内容只按当前格式和列的声明读取，存了别的类型就像其他无效字段一样报告。
- **不自己解析 Markdown**：只显示 Forge 自己渲染的 HTML，先经过白名单过滤，去掉一切能运行、加载、带样式或提交的东西。页面只加载自己的图片，外来的图片和视频变成链接。
- **外部链接只放行 http、https 和 mailto**，用系统自己的应用打开。
- **登录 shell 只用来读用户环境**：Forge CLI 在继承的和登录 shell 的 PATH 上找，与 Agent 找到的是同一个；Agent 从不经由登录 shell 运行。
- **进程检查只看自己的标记**：命令行和其他环境变量从不记录或发送。
