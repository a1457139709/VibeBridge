# 派发只把文本送进 CLI 的输入框

派发把一条指令交给面板里的 Agent，做的就是用户在终端里能做的事：把文本送进 CLI 的输入框。

- **不检查目标**：派发不检查目标面板在做什么，也不检查 skill 是否已安装；Agent 自己处理它收到的输入。
- **文本按键入的内容送入**：CLI 把它当作输入框里键入的内容，不对其中的换行起反应。
- **提交与填入**：派发到新面板时，提交把指令作为启动参数交给它，填入则等它第一次报告就绪后送入；派发到已有运行的面板时，文本接在输入框已有内容之后，提交再按 Enter。
- **何时算已发送**：新面板在请求它时就算已发送；已有面板在文本写完时算已发送。派发记录写在这一刻目标所在的会话上，新面板写在它报告的第一个会话上（ADR 0003）。
