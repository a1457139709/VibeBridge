# 设置按契约读取，非法值回退默认，设置冲突启动时修正

`settings.json` 的读取结果总是落在合法域内：缺失或非法的值使用默认值，`agents`、`shortcuts` 或其中某一项不是对象时整体使用默认值，未知的键保留在文件中并在保存时写回。只有文件不是合法 JSON 对象时读取失败，此时不写入文件。读入的设置存在设置冲突时照常生效，工作台启动时以不可关闭的对话框要求前往对应设置修正，修正前不能离开设置；冲突期间保存其他分类和退出应用照常写入，下次启动重新检测。

## Considered Options

- **非法值使配置无效**：错误显式，但一个字段写错就失去全部设置，且无法在应用内保存修正。
- **只容忍补全默认值产生的快捷键冲突**：需要区分冲突来源，并在写入时省略冲突的补全动作以保留这一区分；用户写出的冲突仍使配置无效。

## Consequences

- 手改 `settings.json` 写错的值不会提示，保存任意分类后被默认值覆盖。
- 合法性只由一份 zod schema 定义：读取在每个字段上回退默认值，保存时报告字段错误。
