# 默认快捷键冲突不视为无效配置

`settings.json` 可以缺少快捷键动作，缺失的动作使用默认组合键；这是当前格式的一部分，不是对旧格式的迁移。快捷键动作会随版本增加，新动作的默认组合键可能与用户已有绑定相同，此时配置照常生效（冲突的组合键由动作列表中靠前的动作响应），工作台启动时以不可关闭的对话框要求用户前往快捷键设置修正，修正并保存前不能离开设置；用户写出的冲突仍使配置无效。

## Considered Options

- **冲突即报错**：与其他无效配置一致，但用户仅因升级就失去全部已有设置，直到手动编辑文件。
- **在编码标准中为快捷键开迁移例外**：保留行为却把它定性为兼容旧格式，削弱“只按当前格式读取”的规则。

## Consequences

- 冲突期间可以保存其他分类；写入文件时省略仍处于冲突的补全动作，使下次启动仍识别为默认快捷键冲突，而不是用户写出的冲突。冲突状态只在快捷键冲突修正后解除。
- 离开设置复用未保存更改对话框：冲突期间即使没有草稿也会弹出，且不提供“不保存”，因为已保存的设置本身带有冲突。
- 冲突期间退出应用不写入 `settings.json`。
