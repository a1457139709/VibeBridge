# Issue 61 面板外观与标题处理访谈记录

关联 [Issue 61](https://github.com/a1457139709/VibeBridge/issues/61)。以下为 2026-10-14 访谈中用户已确认的选择。用户随后调用 Implement skill 授权实施；本轮确认覆盖原票中的统一绿色聚焦及未定底色，GitHub 原票尚未同步这些后续决定。

## 已确认的面板呈现

- 采用原型 B 的可见排版：空间足够时图标与标题横排，横向不足时图标在上、标题在下；矮横框横排。
- Agent 类型色固定由 Agent 类型决定：Codex 绿、Claude 橙、pi 紫。同类型始终使用同一色系，不按项目、面板序号或会话名称随机分配；深浅主题可调整明暗和对比，但保持类型与色系的对应关系。
- 正常／最小面板、导航、设置、添加 Agent 和项目创建引导等涉及 Agent 标识的入口，共用上述类型色关系。
- 最小面板的底色、面板及对应导航条目的选中／聚焦强调色也按 Agent 类型区分，替代本轮原建议的统一绿色。
- 底色和 Agent 图标常驻；选中仍由独立的边框、轮廓及导航反馈表达。两个同类型面板间切换时，前一个恢复未选中。
- 最小面板标题最多两行，矮横框一行；超出部分省略，悬停查看完整标题。相同前缀可能在最小呈现中相同，允许悬停或拉大后区分。
- 沿用 Issue 61 中的浅色白色／中性基础表面规则，类型底色只用于专用最小面板等已确认位置。
- 原型尺寸和切换阈值只是演示参数，不是最终像素要求。正式最小尺寸仍需按真实字体与布局测量。

视觉原型：[compact-panel-prototype.html](../outputs/issue-61/compact-panel-prototype.html)。仅用于可见 UI 与前端交互讨论，不作为生产实现、后台运行、输入输出或生命周期行为的依据；不得复用其代码与软件设计。
