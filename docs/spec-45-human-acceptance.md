# #45 观察版：真实 CLI 与动效验收

范围：[第二阶段交互规格](https://github.com/a1457139709/VibeBridge/issues/45)中必须由使用者确认的真实 CLI 标题、目录重启与手动恢复、放大切换和减弱动态效果。其余功能另有服务及桌面自动验证记录。

本轮是标题观察版：收到的终端标题原样显示，可能带工具名、目录和转圈符号；未收到标题时显示 `Untitled task`。标题清洗属于 #51，须先记录并确认本轮观察结果。

## 准备

从交付目录 `outputs/spec-45-observation/` 双击 `启动观察版.command`。此入口将工作台数据放在同目录的 `data/`，请勿同时打开两个观察版实例。CLI 仍使用本机自己的登录与历史。

准备三个专门的验收目录 A、B、C。在工作台点击“创建项目”，选择 A，窗口数量设为 3，并为 Claude Code、Codex CLI、pi 各分配 1 个，点击“创建并启动”。按 CLI 自己的界面完成登录或目录信任。再用 B 创建一个至少有 2 个面板的项目；C 留空，供目录更改使用。保持足够宽的窗口，展开项目下的面板条目。

如果某个 CLI 无法启动，从导航右下角进入设置，在 Agent 分类填写本机启动命令，再点击“保存 Agent 设置”。“检查命令”用于核对命令是否可用。保存后关闭启动失败的面板，再点项目工具栏“＋”添加对应 Agent；新面板使用刚保存的命令。

记录实际 CLI 版本。本机开始实现时是 Claude Code 2.1.296、Codex CLI 0.162.1、pi 0.84.4；这些版本号不是验收结论。

记录标题时抄写完整文字，包括空格、工具名前缀、目录、分隔符和状态符号。可附截图。每个案例独立执行，原有重要会话不用于重启测试。
