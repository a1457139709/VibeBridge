## 本清单未覆盖的项目

以下项目不能仅靠普通界面操作可靠证明，交由技术验证；不在上面的人工方框里代签。

- **精确标题样本与边界**：用可控 CLI 逐项发出 SPEC 表格的 7 个原始标题，另测无信号、空信号、未知／歧义格式、首尾符号、同文连续更新。真实 CLI 不保证能按需产生这些输入。
- **关闭标题功能**：三种真实 CLI 的原生关闭入口和完整无标题样本尚未确认，不能编造菜单或修改参数来凑测试。应核验“无信号的新运行显示占位”；已有运行只是不再发信号时，不要求超时清空旧标题。
- **真实运行与原始数据**：旧运行迟到标题隔离、同面板重启先清空标题、原始标题与输出逐字不变，以及没有 hook、配置注入、会话文件读取、正文解析或额外命名。这些不能由界面外观证明。
- **拖动内部不变项**：真实终端尺寸和输入对象、进程身份、后台运行连续性、预览期间尚未写盘，及精确几何边界。人工用例只判断可见结果；同类型面板重开后的身份／保存关系仍需技术核验，不能只凭位置相像判定。
